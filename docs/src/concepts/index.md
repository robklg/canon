# Concepts

The core concepts the rest of the book builds on:

- [Roots](roots.md): Storage locations that Canon tracks
- [Sources](source.md): Files discovered on disk
- [Objects](object.md): Unique content identified by hash
- [Sources vs. Objects](source-object.md): How files relate to content
- [Facts](facts.md): Metadata attached to sources or objects
- [Decision Provenance](decisions.md): How Canon records what you did, to what, and why
- [Retirement, the Book, and the Shelf](retirement.md): How a resolved root leaves the index
